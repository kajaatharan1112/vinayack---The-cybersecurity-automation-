# 16-week Master Plan — University + Industry + Practice

**Suggested pace:** ~5 sessions/week, each ~60–90 minutes; change pace as needed. A topic may take multiple days. Quizzes after each chapter, 1 practical portfolio artifact per week.

### Weekly loop
**Day 1:** Definitions and diagrams. **Day 2:** Mechanism and worked example. **Day 3:** Safe lab. **Day 4:** Advanced concepts and misconceptions. **Day 5:** Quiz + correction notebook.

### Mastery proof
- You can explain a packet's path from browser to server with protocols.
- You can subnet accurately and explain routing/switching decisions.
- You can troubleshoot one failure by evidence, not guesses.
- You can separate public IP intelligence from private endpoint telemetry.
- You can explain malware categories and safe response without executing malware.
- You can critically compare modern QUIC/HTTP3, IPv6, Zero Trust, cloud networking, eBPF, Wi-Fi 7, RPKI and post-quantum planning.
